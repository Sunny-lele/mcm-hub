# MCM 建模基本流程

## 1. 数学建模到底在做什么？

数学建模不是“题目给条件，列方程求答案”，而是把现实问题转化为一个可以分析、计算和验证的数学问题。

基本逻辑为：

现实问题 → 提取关键因素 → 作合理简化 → 建立数学关系 → 求解与验证 → 给出结论或建议

例如，某城市希望合理投放共享单车。

需要先考虑：

- 研究对象：各区域、各时段的单车需求；
- 影响因素：人口、地铁站、天气、早晚高峰等；
- 判断标准：用户是否方便借车、车辆是否闲置、调度成本是否过高；
- 最终目标：在满足需求的同时，减少闲置和调度成本。

数学建模的本质是：用一个足够合理的简化模型，帮助解释问题、预测结果或制定方案。

## 2. MCM 常见题目类型

### 2.1 预测类

典型问题：

- 未来会怎样？
- 明年某个指标是多少？
- 某趋势会如何发展？

常用方法：

- 回归分析；
- 时间序列；
- 差分方程；
- 灰色预测；
- 机器学习方法。

例子：根据过去十年人口、GDP 和用电量数据，预测未来五年的用电需求。

---

### 2.2 评价类

典型问题：

- 哪个方案更好？
- 哪个地区最适合？
- 多个对象如何综合排名？

常用方法：

- 指标体系；
- 层次分析法（AHP）；
- 熵权法；
- TOPSIS；
- 主成分分析。

例子：从日照、地形、成本、距离电网、生态影响等角度，评价哪些地区最适合建设太阳能电站。

---

### 2.3 优化类

典型问题：

- 怎样安排最好？
- 如何使成本最低、收益最高？
- 如何在多个目标之间取得平衡？

常用方法：

- 线性规划；
- 整数规划；
- 多目标规划；
- 动态规划；
- 遗传算法、模拟退火等启发式算法。

例子：为外卖配送员规划路线，使总配送成本尽量低，同时减少超时订单。

---

### 2.4 机理类

典型问题：

- 一个系统为什么这样变化？
- 多个因素如何相互作用？
- 系统随时间如何演化？

常用方法：

- 微分方程；
- 差分方程；
- SIR 传染病模型；
- 种群竞争模型；
- 网络传播模型。

例子：研究校园内传染病在不同隔离比例下的传播过程。

---

### 2.5 决策与模拟类

典型问题：

- 某项政策会带来什么后果？
- 存在随机性时，结果可能是什么？
- 多种策略中应选择哪一种？

常用方法：

- 蒙特卡洛模拟；
- 情景分析；
- 风险分析；
- 博弈模型；
- 仿真模型。

例子：模拟不同限行政策下城市交通拥堵程度的变化。

## 3. 一道 MCM 题的标准处理流程

### 第一步：拆分问题

不要直接研究整道题，而要把每一问改写成最朴素的话。

例如：

- 问题一：当前数据有什么规律？
- 问题二：未来会如何变化？
- 问题三：怎样制定最优方案？
- 问题四：方案是否可靠？

每一问通常对应一个小模型或一个分析任务。

---

### 第二步：明确目标

需要先回答：模型最终希望优化、预测、解释或比较什么？

常见目标包括：

- 最大化收益；
- 最小化成本；
- 最小化误差；
- 最大化覆盖率；
- 最大化公平性；
- 预测未来数值；
- 对多个对象进行排序。

数学上常写成：

max f(x)

或：

min f(x)

其中，x 是需要决定的方案或变量，f(x) 是评价方案好坏的目标函数。

---

### 第三步：定义变量、参数和数据

常见概念：

| 名称 | 含义 | 例子 |
|---|---|---|
| 决策变量 | 可以由我们决定的量 | 各区域投放多少辆车 |
| 状态变量 | 系统当前的变化量 | 当前可用单车数、感染人数 |
| 输入数据 | 题目提供或收集到的数据 | 天气、人口、历史订单 |
| 参数 | 模型中相对固定的量 | 单位调度成本、传播率 |
| 输出结果 | 模型最终给出的结论 | 最优方案、未来预测值、综合排名 |

---

### 第四步：作出合理假设

现实问题通常很复杂，因此必须简化。

常见假设：

- 短时间内某些次要因素可以忽略；
- 历史数据能够代表近期趋势；
- 同一类对象具有相似行为；
- 不考虑极端天气、突发政策等偶然事件；
- 数据误差处于可以接受的范围内。

好假设的标准：

1. 能降低问题复杂度；
2. 不破坏主要规律；
3. 能解释为什么这样假设；
4. 后续可以分析该假设带来的局限。

---

### 第五步：选择模型

模型选择要由题目特点决定，而不是先学了某个模型就强行使用。

| 题目特征 | 优先考虑的方法 |
|---|---|
| 研究量随时间连续变化 | 微分方程 |
| 数据按天、月、年递推 | 差分方程、时间序列 |
| 有大量历史数据，需要预测 | 回归、机器学习 |
| 多指标综合比较、排序 | TOPSIS、熵权法、AHP |
| 有明确目标和约束条件 | 规划模型 |
| 有明显随机性 | 蒙特卡洛模拟 |
| 对象之间有连接或传播关系 | 图论、网络模型 |

---

### 第六步：求解、展示结果

求解可以使用：

- 手算推导；
- Python、MATLAB、R 等程序；
- Excel；
- 专业优化软件。

结果展示常用：

- 表格；
- 折线图；
- 散点图；
- 柱状图；
- 热力图；
- 地图；
- 流程图。

注意：图表不是装饰，而是用来证明模型结论。

---

### 第七步：验证模型

模型得到结果后，还需要回答：

“为什么可以相信这个结果？”

常见验证方式：

1. 使用历史数据检验预测误差；
2. 与简单模型或基准方案比较；
3. 改变关键参数，观察结果是否稳定；
4. 分析模型误差来源；
5. 分析模型适用范围和局限性。

其中，改变参数并观察结论变化的过程，称为敏感性分析。

---

## 4. 建模中的“因为—所以”逻辑

一篇好的建模论文，关键不只是公式，而是每一步都有明确理由。

常见表达方式：

- 因为需求量受时间和历史需求影响，所以使用时间序列模型进行预测。
- 因为不同指标的单位不同，不能直接比较，所以先进行标准化处理。
- 因为方案既要求成本低，也要求覆盖率高，所以建立多目标优化模型。
- 因为数据存在误差和不确定性，所以进行敏感性分析。
- 因为现实因素过于复杂，所以忽略影响较小的因素，并在模型局限性中说明。

核心原则：

每一个模型、假设、指标和算法，都应回答“为什么要这样做”。

## 5. 常用建模方法快速判断

```text
题目是否描述一个随时间变化的过程？
├─ 是
│  ├─ 过程连续变化：微分方程
│  ├─ 按天/月/年更新：差分方程、时间序列
│  └─ 主要目的是预测：回归、时间序列、机器学习
└─ 否
   ├─ 要比较多个对象：评价模型
   ├─ 要分配资源、找最优方案：优化模型
   ├─ 存在随机性或风险：蒙特卡洛模拟
   ├─ 对象之间有联系或传播：图论、网络模型
   └─ 数据维度多、规律不明显：降维、聚类、相关性分析
